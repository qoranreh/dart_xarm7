### 0-2. 섭동 구현 (신규 파일만)
LIBERO-Plus (arXiv 2510.13626, github.com/sylvestf/LIBERO-plus) 의 정의를 xArm7 평가 클라이언트에 새로 구현했다. 원 코드는 Panda 용이라 그대로 쓰지 않았다.
- LIBERO-Plus 정의: C1 거리 = 광축을 따라 장면 중심까지 거리 1.01~2.00배, C2 = 장면 중심 기준 방위·고도 15°~75°,
  C3 = 카메라 방향 2°~10° (이번에 안 씀), 로봇 초기 상태 = 팔 qpos + 단위 무작위 방향 × 크기 0.1~0.5 (`new_init.py`: randn 정규화 × 0.1, 0.2 …).
- `eval_perturb.py`: `eval_xarm7.py` 의 평가 루프를 그대로 옮기고 (make_env·LIBERO_DUMMY_ACTION·MAX_STEPS 는 import) 다음만 더함.
  - `--init-offset`: 초기 상태 번호 이동. 기록의 `episode` = 실제 초기 상태 번호. 영상은 태스크마다 `ep == init_offset` 만.
  - `cam_dist` / `cam_azim`: `set_init_state` 뒤 agentview 의 `model.cam_pos/cam_quat` 를 바꾼다 (카메라가 월드 바디에 붙어 있는지 assert).
    LIBERO 는 `hard_reset=True` 라 reset 마다 모델을 새로 만들어 섭동이 에피소드 사이에 쌓이지 않는다.
    장면 중심 = agentview 광축과 테이블 윗면 평면의 교점. 테이블 = 이름에 table 이 든 가장 넓은 상자 geom (`table_collision`, 윗면 z = 0.90 m) → 중심 (−0.221, 0, 0.90), 카메라에서 1.131 m.
    C1: 중심에서 광축 반대로 level 배 거리. C2: 중심을 지나는 연직축으로 ±level° 회전 (부호 = 에피소드 난수), 고도 0.
  - `joint`: `transfer_init_state` (IK) 뒤 팔 7관절 qpos 에 level × 단위 무작위 방향, 관절 한계로 자름. 팔·그리퍼가 환경(마운트 제외)을 새로 파고들면 다시 뽑음 (최대 20회).
  - 난수 `np.random.default_rng([seed, task_id, init_idx])` — 모든 모델이 같은 섭동을 받는다. 전역 np.random 은 건드리지 않는다.
- `check_perturb.py`: `eval_perturb.prepare_episode` (평가와 같은 함수) 로 첫 화면 렌더 + 섭동 크기 집계.
- `run_exp7_pilot.sh`: θ0 서버 1개 + 조건마다 클라이언트 5개. 완료 = 기대 에피소드 수 + errors 0 (아니면 1회 재시도). 영상 홈 복사.
- `exp7_pilot_summary.py`: θ0 성공률, '없음' 대비 하락 (Newcombe CI), 미리 정한 수준 선택 규칙 적용.
